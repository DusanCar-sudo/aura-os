# Task 007 — the Aura OS ISO

Users get Aura OS only as a downloadable ISO (LICENSE). Build it with
Arch's own tool, archiso, inside the VM (mkarchiso runs only on Arch).
Read LICENSE and THIRD-PARTY-NOTICES.md first — they are requirements.

## Deliver
- `iso/` — an archiso profile based on `releng` (copy from
  /usr/share/archiso/configs/releng, then change it; keep the diff small
  and commented).
- Branding: name "Aura OS", ISO label `AURAOS_YYYYMM`, boot menu entries
  "Aura OS installer". Wording "based on Arch Linux" only — no Arch
  logo, nothing implying an official Arch product.
- `pkg/aura-term/PKGBUILD` and `pkg/aura-os/PKGBUILD` → a local pacman
  repo baked into the ISO, so installing needs no compiling:
  - aura-term: built from term/ the PGO way (tools/aura-term-build.sh),
    installs foot's MIT LICENSE to /usr/share/licenses/aura-term/.
  - aura-os: bin/, config/, themes/, install/ → /usr/share/aura-os
    (+ bin/aura-os-* in /usr/bin), license = custom proprietary.
- `iso/airootfs/usr/local/bin/aura-os-installer` — what runs on boot:
  asks disk, user, password, timezone, keyboard (us / sr latin / sr
  cyrillic); runs archinstall with a fixed config (btrfs + snapper
  layout, systemd-boot, pipewire, NetworkManager); then runs
  /usr/share/aura-os/install.sh as the new user's install. No
  Hyprland/SDDM/kitty ever (see 001b).
- First login lands in the finished desktop; a notification says
  "run `aura setup`". No API key, token or user data is ever in the ISO.
- `tools/iso-build.sh` — one command in the VM: build packages, build
  the ISO into ~/iso-out/, write `SHA256SUMS`, and a
  `aura-os-<date>-licenses.txt` (every package + its license).
- `tools/iso-sources.sh` — builds the GPL/LGPL source archive for that
  exact package list (THIRD-PARTY-NOTICES.md). May be slow; it runs
  separately from the ISO build.
- `vm/run-iso-test.sh` — boots the ISO in QEMU with a fresh empty
  disk (not aura-os.qcow2) to test the installer end to end.

## Rules learned the hard way (the behaviour notes)
- The VM is shared: before any reboot, greetd restart or sway reload,
  tell Dusan and wait. Kill processes by PID or exact command line,
  never with a loose pattern (`pkill -f`, `pkill -x foot`).
- Validate before deploying: `sway -C` headless, `bash -n`, JSON parse.
- Look at your own result: `vm/vm-keys.py shot` — a screenshot of the
  first login is part of "done".
- Report host vs guest for every file you wrote.
- Host RAM is tight: never run the ISO test VM while the main VM runs;
  build with `-j2`.

## Done when
- The ISO boots in `vm/run-iso-test.sh`, the installer finishes on an
  empty disk, and after reboot: greetd → sway, the Aura OS desktop, sidebar,
  aura-term, Firefox launches, **sound plays** (task 004 lesson),
  aura-os-bench idle < 350 MB. Screenshot of that first desktop.
- `pacman -Qi aura-term` shows the MIT license file installed.
- `SHA256SUMS`, the licenses list and the ISO size in the report.
- The source archive: its size and how long it took (or why skipped).
