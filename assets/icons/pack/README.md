# Aura OS Icon Bundle

A compact monochrome icon system designed for Aura OS:
- 24×24 viewBox
- `currentColor` for instant theme compatibility
- square caps / miter joins
- no gradients, blur, or decorative noise
- tuned for 16–24 px UI use
- original Aura mark; no Arch Linux logo usage

## Naming
`aura-mark.svg` is the brand mark.
The remaining icons map to system surfaces and commands.

The apps directory adds simplified monochrome glyphs for Chrome, Firefox,
VS Code, GitHub, Docker, Discord, Slack, Spotify, YouTube, OBS Studio, Steam,
Unity, Figma, and ChatGPT. They use the same 24×24 grid and are reduced to
the visual cues that remain recognizable at small sizes rather than full-color
launcher artwork.

## Recommended UI sizes
- Sidebar / status: 16 px
- Menus / settings: 18–20 px
- Launcher tiles / empty states: 24–32 px

## Styling rule
Use icons as anchors, not decoration. Aura OS is text-first.
Prefer icon + terse label over icon-only controls except for universally recognizable actions.
